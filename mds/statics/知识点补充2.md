### 1.<font style="color:rgb(0, 0, 0);">EventSource</font>（SSE单向通信）
相比 WebSocket，EventSource 是**<font style="color:#DF2A3F;">单向通信</font>**，它属于 Server-Sent Events (**<font style="color:#DF2A3F;">SSE</font>**) 机制，仅支持服务器向客户端发送数据，适用于**<font style="color:#DF2A3F;">实时更新</font>**场景，如新闻推送、股票价格。

特点：

+ 单向通信：服务器向客户端
+ 自动重连：连接断开自动重连
+ 轻量级：基于http协议，比websocket更轻量

使用：

```javascript
const http = require('http');

http.createServer((req, res) => {
  const query = url.parse(req.url, true).query;
  const token = query.token;
  const userId = query.userId;

  console.log(`Received token: ${token}, userId: ${userId}`);
  res.writeHead(200, {
    'Content-Type': 'text/event-stream',
    'Cache-Control': 'no-cache',
    'Connection': 'keep-alive',
  });

  setInterval(() => {
    res.write(`data: Server time: ${new Date().toLocaleTimeString()}\n\n`);
  }, 3000);
}).listen(3000, () => {
  console.log('Server running on port 3000');
});
```

注意：服务端必须指定响应类型：Content-Type: "text/event-stream"

客户端接受消息：

```javascript
const eventSource = new EventSource('http://localhost:3000?token=abc&user=admin');

// 监听服务器发送的消息
eventSource.onmessage = function(event) {
  console.log('Received message:', event.data);
};

// 监听连接打开事件
eventSource.onopen = function() {
  console.log('Connection opened');
};

// 监听错误事件
eventSource.onerror = function(event) {
  console.error('Error occurred:', event);
  eventSource.close(); // 关闭连接
};
```

### 2.浏览器跨标签页面通信
#### BroadcastChannel 广播
BroadcastChannel 是现代浏览器提供的一种 跨页面通信（Cross-Page Communication）API，允许你在 同一个域名下的不同浏览器标签页、iframe 或窗口之间发送和接收消息。

使用场景：

+ 多标签页登录状态
+ 页面间数据共享
+ 实时通知广播

```javascript
//  页面1 发送
let channel = new BroadcastChannel('qux');
// 发送消息
channel.postMessage({
  type: 'notice',
  msg: 'hello world'
});

// 页面2 接收
let channel = new BroadcastChannel('qux');
// 发送消息
channel.onmessage = (e) => {
  console.log(e.data); // { type: 'notice', msg: 'hello world'}
}
```

#### ServiceWorker
Service Worker是现代 Web 应用中一个强大的后台脚本，它运行在浏览器主线程之外，作为网络代理，让你可以完全控制页面的网络请求、实现离线访问、推送通知、后台同步等功能。

它是构建 PWA（Progressive Web App，渐进式 Web 应用） 的核心技术之一。

生命周期：

+ 注册 Register
+ 安装 Install
+ 激活 Activate
+ 运行 Fetch / Message / Push 等事件

```javascript
// 页面1
navigator.serviceWorker.register('sw.js').then(() => {
  console.log("service worker 注册成功");
});
document.querySelector("button").onclick = function () {
  navigator.serviceWorker.controller.postMessage('hello');
}

// 页面2
navigator.serviceWorker.register('sw.js').then(() => {
  console.log("service worker 注册成功");
});
navigator.serviceWorker.onmessage = function ({ data }) {
  console.log(data);
}

// sw.js
self.addEventListener("message",async event=>{
  const clients = await self.clients.matchAll();
  clients.forEach(function(client){
    client.postMessage(event.data)
  });
});
```

```plain

+ 第二类：鼠标交互-移入和移出

```

+ 第三类：输入框焦点事件

```javascript
focus, blur
```

**<font style="color:rgb(17, 17, 51);"></font>**

**<font style="color:rgb(17, 17, 51);">如何判断事件是否会冒泡？</font>**

<font style="color:rgb(17, 17, 51);">通过</font>**<font style="color:#DF2A3F;">bubbles</font>**<font style="color:rgb(17, 17, 51);">属性（每个event都有的属性）判断：</font>

### 4.MessageChannel消息通道
MessageChannel<font style="color:rgb(0, 0, 0);">允许我们创建一个新的消息通道，返回一个双信道的对象。</font>

<font style="color:rgb(0, 0, 0);">只能在创建它们的同一个上下文或通过 </font>**<font style="color:#DF2A3F;">postMessage</font>**<font style="color:rgb(0, 0, 0);"> 显式传递端口的上下文中使用。不能实现夸标签页通信！</font>

+ <font style="color:rgb(0, 0, 0);">Worker上下文使用</font>

```javascript
// main.js
const worker = new Worker('worker.js');
const channel = new MessageChannel();

// 通过postMessage将 port2 发送给 Worker上下文
worker.postMessage('init', [channel.port2]); // 注意：必须传入 [port] 作为 Transferable

// port1 留给主线程使用
channel.port1.onmessage = function(event) {
  console.log('主线程收到:', event.data);
};

// 发送消息给 Worker
channel.port1.postMessage('你好，Worker！');


// worker.js
// 接收主页面发来的 port2
self.onmessage = function(event) {
  if (event.data === 'init') {
    let port = event.ports[0]; // 接收到的端口
    port.onmessage = function(event) {
      console.log('Worker 收到:', event.data);
      // 回复
      port.postMessage('Worker 回应：' + event.data);
    };
  }
};
```

+ iframe上下文使用

```javascript
// parent.html
const iframe = document.getElementById('myIframe');
const channel = new MessageChannel();

// 向 iframe 发送 port1
iframe.contentWindow.postMessage('init', '*', [channel.port1]);

// 监听来自 iframe 的消息
channel.port2.onmessage = function(event) {
  console.log('来自 iframe 的消息:', event.data);
};


// child.html (iframe 内容)
window.addEventListener('message', function(event) {
  if (event.data === 'init' && event.ports.length > 0) {
    let port = event.ports[0];
    port.onmessage = function(e) {
      console.log('收到主页面消息:', e.data);
      port.postMessage('已收到');
    };
  }
});
```

### 5.深拷贝与浅拷贝
#### 定义
**浅拷贝**：遇到引入类型仅拷贝引入地址，遇到基本类型拷贝值；

**深拷贝**：完全（深层次）拷贝对象，包括对象的内存数据（<font style="color:#DF2A3F;">修改新对象，旧对象不会改变</font>）；

#### 如何判断是否是深拷贝？
修改新对象，旧对象不变就是深拷贝，旧对象改变就是浅拷贝。

#### 深拷贝都有哪些？
+ **<font style="color:rgb(60, 60, 67);">递归循环</font>**

```javascript
function deepClone(obj) {
  // 处理 null 或非对象类型
  if (obj === null || typeof obj !== 'object') {
    return obj;
  }

  // 处理日期
  if (obj instanceof Date) {
    return new Date(obj);
  }

  // 处理正则
  if (obj instanceof RegExp) {
    return new RegExp(obj.source, obj.flags);
  }

  // 处理数组或对象
  const clone = Array.isArray(obj) ? [] : {};

  // 递归复制每个属性
  for (let key in obj) {
    if (obj.hasOwnProperty(key)) {
      clone[key] = deepClone(obj[key]);
    }
  }

  return clone;
}
```

+ **<font style="color:rgb(60, 60, 67);">JSON 实现深拷贝，</font>**<font style="color:rgb(60, 60, 67);">对函数、Symbol、循环引用、正则、Date、undefined等不是完全拷贝</font>

```javascript
const copy = JSON.parse(JSON.stringify(original));
```

+ **structuredClone() 现代浏览器新API，**不支持函数、Symbol 等特殊类型

```javascript
const copy = structuredClone(original);
```

#### 浅拷贝都有哪些？
+ **Object.assign(target, obj1, obj2...)，**<font style="color:rgb(60, 60, 67);">修改引用类型会受影响</font>

```javascript
const obj = Object.assign({}, source1 );
```

+ **<font style="color:rgb(60, 60, 67);">...扩展运算符，</font>**<font style="color:rgb(60, 60, 67);"> 修改引用类型会受影响</font>

```javascript
let obj1 = { a:1, b:{c:3}}
let obj2 = {...obj1}
```

+ **Object.create()， **复制顶层结构，对于嵌套的引用类型（对象、数组等）只复制引用

```javascript
const copy = Object.create(
  Object.getPrototypeOf(original),
  Object.getOwnPropertyDescriptors(original)
);
```

### 7.try...catch是否可以捕获异步操作的错误？

### 12.ResizeObserver 如何监听元素尺寸的变化？
ResizeObserver 是现代浏览器提供的一个 Web API，用于**<font style="color:#DF2A3F;">监听 DOM 元素的尺寸变化（如宽度、高度）</font>**。它是替代 onresize（仅限 window）和轮询检测尺寸的现代、高效方案。

```javascript
const observer = new ResizeObserver((item) => {
  item.forEach((e) => console.log('尺寸变化', e.contentRect));
});

// 开始观察一个或多个元素
observer.observe(targetElement);

// 停止观察
observer.unobserve(targetElement);

// 停止所有观察
observer.disconnect();
```

### 13.MutationObserver 如何监听元素内容及属性变化？
MutationObserver 是一个 Web API，用于异步监听 DOM 树的变化。包括：子元素，元素属性、子元素删除都可以监听到。

```javascript
const editor = document.getElementById('editor');

const observer = new MutationObserver(mutations => {
  mutations.forEach(mutation => {
    // 处理变化 mutation
    // type：'attributes', 'childList', 'characterData'
  });
});

observer.observe(editor, {
  attributes: true,      // 属性变化
  childList: true,       // 子节点增删
  subtree: true,         // 后代节点
  characterData: true    // 文本变化
});

// 停止监听
observer.disconnect();
```

### 14.defer和async的区别？
<font style="color:rgb(37, 41, 51);">JavaScript 的加载方式直接影响页面的首屏渲染时间、交互响应速度和用户体验。使用defer 和 async可以优化加载速度。</font>

+ 默认，解析时遇到script，会暂停 HTML 解析，立即下载并执行脚本，继续解析 HTML
+ defer，解析时遇到script，会**<font style="color:#4861E0;">下载脚本但不执行</font>**，html执行完毕后，DOMContentLoaded 前顺序执行脚本
+ async，解析时遇到script，会**<font style="color:#DF2A3F;">异步下载并立即执行</font>**脚本。

共同点：都不会阻塞渲染进程。

不同点：下载和执行时机不同。

### 15.协商缓存和强缓存区别？
答：核心区别：<font style="color:rgb(37, 41, 51);">在于</font>**<font style="color:#D22D8D;">是否向服务器发送请求</font>**<font style="color:rgb(37, 41, 51);">以及</font>**<font style="color:#117CEE;">如何处理缓存更新</font>**<font style="color:rgb(37, 41, 51);">。</font>

<font style="color:rgb(37, 41, 51);">浏览器缓存顺序：先检查是否命中强缓存（Cache-Control 或 Expires）；若强缓存未命中，则进入协商缓存流程，发送请求并带上验证字段，服务器根据验证字段决定返回 </font>`<font style="color:rgb(255, 80, 44);background-color:rgb(255, 245, 245);">304</font>`<font style="color:rgb(37, 41, 51);"> 还是新资源。</font>

#### <font style="color:rgb(37, 41, 51);">强缓存</font>
**<font style="color:rgb(37, 41, 51);">强缓存特点</font>**<font style="color:rgb(37, 41, 51);">：</font>

+ 不发送请求：直接从本地缓存读取
+ 状态码：200

**强缓存开启：**

+ **<font style="color:#DF2A3F;">Cache-Control</font>**<font style="color:#DF2A3F;">: max-age</font>=秒数（推荐）
+ ~~Expires 绝对时间（已不推荐使用）~~

**应用场景：长时间不变的图片/js/css资源**

**优点：速度快，减轻服务器压力**

**缺点：有可能不是最新代码。**

#### 协商缓存
**协商缓存特定：**

+ 发送请求，向服务器<font style="color:rgb(37, 41, 51);">验证资源是否更新</font>
+ <font style="color:rgb(37, 41, 51);">状态码：304-不更新使用缓存、200-更新</font>

**<font style="color:rgb(37, 41, 51);">协商缓存开启：</font>**

+ **<font style="color:#DF2A3F;">Cache-Control: no-cache + ETag</font>**     —— ETag / If-None-Match（推荐）
+ **<font style="color:#DF2A3F;">Last-Modified</font>** / If-Modified-Since（次选）

**应用场景**：频繁更新的内容：api,html

优点：更新即时

确定：频繁请求

### 16.Promise是同步还是异步？
答：<font style="color:#2F4BDA;">promise</font>()函数**<font style="color:#DF2A3F;">本身是同步函数</font>**，但<font style="color:#2F4BDA;">then</font>()函数式异步**<font style="color:#2F4BDA;">微任务</font>**！

在遇到promise.then时，自身函数回调会随同步顺序先执行，并将then回调放到微队列里面，所有的then函数（微队列）执行完毕之后才会执行宏队列。
