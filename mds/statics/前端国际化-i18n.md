前端项目里国际化方案，最推荐的就是i18n库，针对这个库，还分了：i18next和vue-i18n。

### <font style="color:rgb(17, 17, 51);">i18next</font>
通用国际化解决方案，采用 “核心 + 插件” 架构：

+ i18next: 核心逻辑 
+ i18next-browser-languagedetector: 自动检测浏览器语言 
+ i18next-http-backend: 从服务器加载语言包 
+ i18next-localstorage-backend: 缓存翻译到localStorage 
+ react-i18next, vue-i18next: 框架绑定

安装：

```bash
npm install i18next i18next-browser-languagedetector i18next-http-backend vue-i18next
```

使用：

```javascript
// i18n.js
import i18n from 'i18next';
import { createI18n } from 'vue-i18next';
import Backend from 'i18next-http-backend';
import LanguageDetector from 'i18next-browser-languagedetector';

i18n
  .use(Backend)
  .use(LanguageDetector)
  .init({
    fallbackLng: 'en',
    debug: true,
    interpolation: { escapeValue: false },
  });

export const i18nVue = createI18n({ i18n });

// main.js
import { createApp } from 'vue';
import { i18nVue } from './i18n';
import App from './App.vue';

createApp(App).use(i18nVue).mount('#app');


<!-- 组件中 -->
<template>
  <p>{{ t('message.hello') }}</p>
</template>

<script setup>
import { useI18n } from 'vue-i18next';
const { t } = useI18n();
</script>
```

### vue-i18n
专为 Vue 设计 的国际化插件，开箱即用。

安装:

```bash
npm install vue-i18n@next
```

使用：

```javascript
// i18n.js
import { createI18n } from 'vue-i18n';

const messages = {
  en: {
    message: {
      hello: 'hello world'
    }
  },
  zh: {
    message: {
      hello: '你好世界'
    }
  }
};

const i18n = createI18n({
  locale: 'zh', // 默认语言
  fallbackLocale: 'en',
  messages,
});

export default i18n;


// main.js
import { createApp } from 'vue';
import i18n from './i18n';
import App from './App.vue';

createApp(App).use(i18n).mount('#app');

<!-- 组件中 -->
<template>
  <p>{{ $t('message.hello') }}</p>
</template>
```

### 如何选择？
单一vue技术栈，选择vue-i18n

后续会可能迁移到其他框架，选择i18next
