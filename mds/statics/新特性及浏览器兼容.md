### flex:1
Firefox（火狐）和 Chrome（谷歌）浏览器在某些特定场景下对 flex: 1 的布局效果不一样，特别是对 min-width: auto 和 min-width: 0 的处理。

Chrome 默认对 flex 项目应用 min-width: 0（或类似行为）来防止溢出。

Firefox 更严格地遵循规范，保持 min-width: auto，即项目至少要能容纳其内容的最小宽度。

火狐要与谷歌保持一致：

```css
/*兼容写法*/
.flex1{
    flex: 1 1 0px;
    min-width: 0;
}
```

### arr.toSorted()
toSorted 返回一个新数组，其元素按升序排列。用法同sort。

sort 虽然也是升序排列，但是会影响原数组顺序。

```javascript
const values = [1, 10, 21, 2];
const sortedValues = values.toSorted((a, b) => a - b);
```

### arr.toReversed()
toReversed 包含以相反顺序排列元素的新数组。用法同reverse。

reverse也能实现反序排列，但是会影响原数组顺序。

```javascript
const items = [1, 2, 3];
const reversedItems = items.toReversed(); // [3, 2, 1]
```

### arr.with(index,value）
返回一个全新的数组，其中 index 索引处的元素被替换为 value。

```javascript
const arr = [1, 2, 3, 4, 5];
console.log(arr.with(2, 6)); // [1, 2, 6, 4, 5]
console.log(arr); // [1, 2, 3, 4, 5]
```

### arr.<font style="color:rgb(0, 0, 0);">toSpliced()</font>
<font style="color:rgb(0, 0, 0);">返回一个新数组，并在给定的索引处删除和/或替换了一些元素。用法同splice函数，但不改变原始数组。</font>

```javascript
toSpliced(start)
toSpliced(start, deleteCount)
toSpliced(start, deleteCount, item1)
toSpliced(start, deleteCount, item1, item2, itemN)


const months = ["Jan", "Mar", "Apr", "May"];
const months2 = months.toSpliced(1, 0, "Feb"); // ["Jan", "Feb", "Mar", "Apr", "May"]
const months3 = months2.toSpliced(2, 2); // ["Jan", "Feb", "May"]
```

### obj.groupBy()
<font style="color:rgb(0, 0, 0);">使用某个任意值作为键来对元素进行分组，返回一个带有所有分组的对象。</font>

```javascript
const inventory = [
  { name: "芦笋", type: "蔬菜", quantity: 5 },
  { name: "香蕉", type: "水果", quantity: 0 },
  { name: "山羊", type: "肉", quantity: 23 },
  { name: "樱桃", type: "水果", quantity: 5 },
  { name: "鱼", type: "肉", quantity: 22 },
];
const result = Object.groupBy(inventory, ({ type }) => type);
/* 结果是：
{
  蔬菜: [
    { name: "芦笋", type: "蔬菜", quantity: 5 },
  ],
  水果: [
    { name: "香蕉", type: "水果", quantity: 0 },
    { name: "樱桃", type: "水果", quantity: 5 }
  ],
  肉: [
    { name: "山羊", type: "肉", quantity: 23 },
    { name: "鱼", type: "肉", quantity: 22 }
  ]
}
*/
```
